## Featured Projects

### 🧪 CyberRecon: QR-code C2, studied defensively
Reproduced a QR-code browser-isolation bypass in an isolated lab, then hardened it with AES-256-GCM payloads and authenticated channels. Fixed 10 CWEs and documented detection signatures.
**Stack:** Python · Flask · OpenCV · [View on GitHub](https://github.com/Jeevan1725/cyberrecon)

### 🛒 AquaShop: vulnerable and secure web app
An aquarium e-commerce site with a one-click toggle that switches the whole app between VULNERABLE and SECURE modes. Covers 12 flaws (SQLi, XSS, IDOR, CSRF, path traversal, file-upload RCE and more), each with a working attack, fix and write-up.
**Stack:** PHP 8 · MySQL · Apache · Vanilla JS · [View on GitHub](https://github.com/Jeevan1725/aquashop)

### 🔒 Secured Notepad: encrypted notes app
A desktop notes app with client-side AES-256 encryption, bcrypt authentication and MySQL-backed encrypted CRUD.
**Stack:** Python · Tkinter · MySQL · [View on GitHub](https://github.com/Jeevan1725/Secured-Notepad-Application)

## How I Work

**Recon → Assess → Exploit → Report → Harden**

1. **Recon:** Map the system's inputs, users, trust boundaries and attack surface
2. **Assess:** Test inputs, sessions and access controls to find weaknesses
3. **Exploit:** Build a safe proof of concept so the risk is clear
4. **Report:** Write concise findings anyone on the team can act on
5. **Harden:** Recommend fixes, verify them, and document what I learned
